# fullstackopen-part3

Simple phonebook app that supports adding and deleting contacts.

Per exercise instructions, names must be at least 3 characters in length. Number validation is unorthodox and requires at least 8 digits and exactly one hyphen, with the number of digits preceding the hyphen to be either 2 or 3.

Deployed [here](https://fullstackopen-part3-production-63bf.up.railway.app/).
